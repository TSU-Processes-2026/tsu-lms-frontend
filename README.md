# tsu-lms-frontend
LMS для учебной команды: предметы, лента постов (объявления, материалы, задания), решения и проверки, комментарии ко всем сущностям. Разработка бизнес‑логики по TDD, веб‑интерфейс.

## Локальный запуск (Windows/macOS/Linux)
1. Установите Node.js LTS (рекомендуется 20+).
2. В корне проекта выполните установку зависимостей:
   - `npm install`
3. Запустите dev-сервер:
   - `npm run dev`

> Если появляется ошибка `"vite" не является внутренней или внешней командой`, значит зависимости не установлены (или установка завершилась с ошибкой). Сначала выполните `npm install`, затем повторите `npm run dev`.
